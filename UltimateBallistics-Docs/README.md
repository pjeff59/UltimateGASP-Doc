## Scope and requirements

- Use the Unreal Engine version targeted by the plugin package you received. The plugin metadata does not specify a minimum engine version.
- The plugin is marked as beta and is intended for single-player gameplay.
- Enable the plugin and any required dependencies included with your plugin distribution. Do not mix files from different plugin packages.
- Projectile meshes, Niagara systems, sounds, and decal materials are optional project assets that you provide if you want those visuals or sounds.
