# UltimateHUD documentation

UltimateHUD helps you manage HUD elements and send interface notifications from Blueprints. You create the visual widgets and connect them to your game.

**Start here:** [Blueprint user guide](USER_GUIDE.md)

The guide covers installation, a first health bar, element setup, data updates, visibility, themes, notifications, practical examples and troubleshooting. It describes the behavior of the current plugin rather than promising ready-made artwork or automatic gameplay connections.
